The active pages overlap independently animated connected branch layers. The homepage welcome section additionally uses the four original gallery assets and both About assets, in nine independent layers with slightly stronger breeze and delayed terminal-sprig motion. Journal and FAQ no longer load botanical styles, scripts or images. CSS anchors the woody attachments beyond the canvas edges. Shared hero sizing preserves the 3416 × 1984 reference ratio on wide screens, with a taller minimum height on small screens for the heading and visible foliage. Reduced-motion preferences disable the breeze.

# Generated bougainvillea assets

Generated with the built-in image_gen tool for the gallery botanical animation. All four PNGs include genuine alpha transparency. The CSS composition scales from a 3416 × 1984 reference canvas; attachment points are kept at or beyond the scene edges. No existing flower imagery is used.

The gallery arrangement now surrounds its heading in a single taller ivory hero. Shared styling and visibility pausing live in `botanical-heroes.css` and `botanical-heroes.js`. For the eight additional, page-specific PNG assets and their complete generation prompts, see [page-variants.md](page-variants.md).

## Files

- canopy.png: 1536 × 1024, dense connected canopy branch.
- trailing.png: 1024 × 1536, long hanging connected branch.
- diagonal.png: 1536 × 1024, branch growing from lower-right toward upper-left.
- sprig.png: 1024 × 1536, lighter connected trailing branch.
